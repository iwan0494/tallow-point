1. **E keluar mobil → game FREEZE total** (pageerror `Cannot read properties of null (reading 'heading')`, main.js:233). Penyebab: variabel lokal `driving` dihitung di awal `update()`, lalu E-exit mengubah `player.state.driving` jadi null — baris `state.heading = driving ? player.state.driving.heading : …` membaca `.heading` dari null, exception membunuh `requestAnimationFrame` loop. **Fix:** recompute `driving = !!player.state.driving` sebelum blok Movement; + try/catch di dalam `loop()` supaya satu frame error tidak pernah membekukan game.
2. **Shot 4 BUSTED** (run screenshot pertama: mode `busted`, bukan chase). Penyebab tidak 100% ter-reproduksi (probe 30 dtk: tetap playing), tapi mobil terbukti nyangkut di belakang mobil traffic lambat (151 → 17 km/h). **Fix:** (a) `state.staging = true` saat `?shot=` aktif → BUSTED/WASTED dinonaktifkan selama staging; (b) tabrakan traffic: mobil traffic didorong ke depan + kecepatan pemain cuma ×0,85 (dulu ×0,6) supaya chase tidak macet; (c) `setWanted()` kini hanya set heat — transisi wanted + spawn roadblock digerakkan `update()` (sebelumnya set langsung `wanted`, roadblock tidak pernah muncul di shot staging).
